Welcome to VirtIO-OS!

This is a bare-metal AArch64 operating system running on QEMU.

Features:
- Virtio device drivers (rng, blk, net, gpu, input)
- Preemptive multitasking with timer IRQ
- Per-process virtual address spaces
- Memory isolation with guard pages
- FAT16 filesystem
- Unix-style file descriptors
- Interactive shell

Type 'help' in the shell for commands.
